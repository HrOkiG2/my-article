AWS Storage Gatewayの概要と、3つのモード(File、Volume、Tape)をまとめました。
オンプレミスとAWSをつなぐストレージサービスを、整理したい方に向けた内容です。

## 結論

Storage Gatewayは、**オンプレミスとAWSのクラウドストレージをつなぐ、ハイブリッドクラウドストレージサービス**です。
File Gateway、Volume Gateway、Tape Gatewayの3つのモードから、用途に合わせて選びます。

## AWS Storage Gatewayとは

オンプレミスのアプリケーションが、AWSのクラウドストレージを、ストレージのバックエンドとして使えるようにするサービスです。
主な目的は、次の3つです。

1. **オンプレミスのストレージコスト削減**: クラウドストレージを使って、物理ストレージ機器の購入や管理コストを減らします。
2. **バックアップとアーカイブ**: オンプレミスのデータを、S3やS3 Glacierに効率よくバックアップします。
3. **クラウドのデータ活用**: AWSにデータを置くことで、AthenaやRedshiftなどで、高度な分析やレポート生成ができます。

:::message
アプリケーションをオンプレミスに残したまま、クラウドの恩恵を受けられます。
S3やAmazon FSx for Windows File Serverを使うことで、**11ナインの耐久性**や、コストの低下といった恩恵を受けられます。
:::

### ハイブリッド環境を作るには

公式にも書かれているように、仮想マシンやハードウェアアプライアンスで、オンプレ環境にStorage Gatewayをデプロイします。
構築方法は割愛しますが、「オンプレ環境に、AWSとつなぐサーバーを置く」くらいの理解で十分です。

> Storage Gatewayをセットアップするには、まず、作成するゲートウェイのタイプと、ゲートウェイ仮想アプライアンスを実行するホストプラットフォームを選択します。(中略)Storage Gatewayは、優先リセラーに注文した物理ハードウェアアプライアンスとして、またはAWSクラウド環境のAmazon EC2インスタンスとしてデプロイすることもできます。
>
> (出典: [ゲートウェイの作成](https://docs.aws.amazon.com/ja_jp/storagegateway/latest/vgw/creating-your-gateway.html))

## 3つのモード

### File Gateway

| 項目 | 説明 |
| --- | --- |
| 目的 | オンプレミスのアプリが、S3などのクラウドストレージを、ファイルサーバーのように使えるようにします。 |
| ユースケース | ファイルのバックアップ・アーカイブ、データ共有 |
| 仕組み | NFSやSMBプロトコルで、オンプレのアプリからアクセスできます。データはS3に保存されます。 |

オンプレの環境に合わせて、ゲートウェイを選べる点がよいと感じました。
(自社開発の時代はLinux環境が多かったのですが、受託開発の時代はWindows環境にもアクセスする必要がありました。選択肢が広いのは、さすがAWSです。)

| タイプ | 特徴 | ユースケース |
| --- | --- | --- |
| **S3 File Gateway** | オンプレからS3へのファイルアップロードを簡単にします。ローカルキャッシュで、高いアクセス速度を実現します。 | バックアップやアーカイブの簡略化、データ共有、S3のライフサイクルポリシーによるコスト削減 |
| **Amazon FSx File Gateway** | オンプレのアプリを、Amazon FSxのファイルシステムに接続します。SMBをサポートして、Windows環境に最適です。Active Directory統合で、高度なアクセス制御ができます。 | クラウド上のWindowsファイルサーバー、既存のWindowsアプリとの統合、ディザスタリカバリ、ファイル共有 |

### Volume Gateway

| 項目 | 説明 |
| --- | --- |
| 目的 | ブロックストレージのワークロードを、クラウドに統合します。 |
| ユースケース | データセンターのバックアップ(スナップショット)、ディザスタリカバリ |
| モード | **キャッシュ型ボリューム**: 頻繁にアクセスするデータをローカルにキャッシュして、全データはクラウドに保存します。<br>**保管型ボリューム**: 全データをローカルに保持して、AWSクラウドに非同期でバックアップします。 |

ユースケースや要件に応じて選べるのは、AWSのよいところであり、迷いやすいところでもあります。

### Tape Gateway

| 項目 | 説明 |
| --- | --- |
| 目的 | 従来のテープバックアップを、クラウド環境に置き換えます。 |
| ユースケース | 長期的なデータ保存やコンプライアンス、テープライブラリのコスト削減 |
| 仕組み | 仮想テープライブラリ(VTL)を提供して、S3やS3 Glacierにデータを保存します。 |

## Storage Gatewayのメリット

1. **コスト効率**: 従来のオンプレミスストレージに比べて、初期投資や運用コストを大きく減らせます。
2. **スケーラビリティ**: クラウドストレージなので、容量を気にせず、必要に応じて拡張できます。
3. **AWSサービスとの連携**: S3、Glacier、Athena、Redshiftなどと連携して、データをさらに活用できます。
4. **簡単な導入**: 仮想アプライアンスとしてデプロイできて、オンプレ環境に素早く統合できます。
5. **セキュリティ**: データは、転送中も保存時も暗号化され、AWSの強固なセキュリティ基準を満たしています。

## まとめ

* Storage Gatewayは、オンプレミスとクラウドをつなぐ、ハイブリッドストレージサービスです。
* File Gateway、Volume Gateway、Tape Gatewayの3つのモードがあります。
* バックアップ、アーカイブ、データ活用の用途で、コスト削減や運用の効率化ができます。
