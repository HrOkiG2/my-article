英語の学習として、RDS for MySQLのアップグレード作業の前日の気持ちを書いた日記です。
初めてのDBアップグレードに不安を感じている方に向けた、短い記録になります。

## English

I have a task to upgrade RDS for MySQL.
It is a very hard task for me. I find it difficult for several reasons.

1. The DB has never been upgraded before, so unexpected events may occur.
2. My teammates, including myself, don't know how to upgrade.
3. If the DB stops while many end users are using the service, it will be a big problem.

If I can clear this, it will allow me to climb one staircase.
Let's goooooooo!

## 日本語

RDS for MySQLのアップグレード作業があります。
私にとっては、とても難しい作業で、難しいと感じる理由がいくつかあります。

1. このDBは、一度もアップグレードされたことがなく、予期しないことが起こるかもしれません。
2. 自分を含めて、チームの誰も、アップグレードの方法を知りません。
3. 多くのエンドユーザーが使っているときに、DBが止まったら、大問題です。

これをクリアできれば、1段階、階段を上れるはずです。
行くぞ!

## まとめ

* 初めてのDBアップグレードは、不安がたくさんあります。
* それでも、クリアできれば、大きな成長になります。
