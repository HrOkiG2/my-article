PHPで、アップロードされた写真からExifデータ(撮影日時や位置情報など)を削除する方法をまとめました。
ユーザーから写真を受け取るサイトやアプリを作っている、PHPエンジニアの方に向けた内容です。

## 結論

GDライブラリで画像を読み込み、新しいファイルとして保存し直せば、Exifデータが取り除かれます。

## Exifデータって何？

Exifデータは、デジタル写真に含まれる「隠れた情報」です。
撮影日時や場所、使われたカメラの設定などが含まれています。

便利な情報ですが、プライバシーが漏れる原因にもなります。
写真をネットにアップする前には、Exifデータを削除しておくのが安全です。

## PHPでExifデータを消す

PHPで画像を処理するときによく使われる、GDライブラリを使います。

```php
<?php
$image = imagecreatefromjpeg('example.jpg'); // JPEG画像を読み込む
imagejpeg($image, 'result.jpg');             // 画像を保存することでExifデータを削除
imagedestroy($image);                        // メモリを解放
?>
```

やっていることは、次のとおりです。

* `imagecreatefromjpeg` で画像を読み込みます。
* `imagejpeg` で、新しいファイルとして画像を保存します。

この保存のときに、Exifデータが取り除かれます。

:::message
`imagecreatefromjpeg` は、手軽に確認したくて使いました。
PNGやGIFなど、使う画像形式に合わせて、適切な関数を使ってください。
:::

## 画質を指定して保存する

`imagejpeg` の第3引数に、画質(0〜100)を指定できます。100が最高画質です。

```php
imagejpeg($image, 'result.jpg', 100);
```

:::message alert
JPEGを保存し直すので、再圧縮による画質の劣化はゼロにはなりません。
画質100にすれば劣化を最小限にできますが、元の画質と完全に同じにはならない点に注意してください。
また、Exifに含まれる向き(Orientation)の情報も消えるため、スマホで撮った写真が横向きや逆向きになることがあります。
必要なら、削除する前に向きを補正しておきましょう。
:::

## まとめ

* Exifデータには、撮影日時や場所などのプライバシー情報が含まれます。
* GDで読み込んで保存し直すと、Exifデータを削除できます。
* 画質は `imagejpeg` の第3引数で指定できますが、再圧縮による劣化は避けられません。
* ユーザーから写真を受け取るときは、この処理を入れておくと安心です。
