`ssh-keygen` で、ed25519の鍵を、ファイル名を指定して作る方法をまとめました。
SSH接続を、鍵認証にしたい方に向けた短いメモです。

## 結論

次のコマンドで、ed25519の鍵ペアを、好きなファイル名で作れます。

```bash
ssh-keygen -t ed25519 -C メールアドレス -f myfile-ssh
```

## 用途

鍵認証で使います。
守りたいものがある場合、パスワード認証だと不安なので、基本的に鍵認証にしましょう。
(以前、クラウドサーバーへのSSH接続を、パスワード認証にしていた現場を思い出すと、ぞっとします。)

## コマンド

| オプション | 意味 |
| --- | --- |
| `-t` | 暗号アルゴリズムです。`rsa` なども指定できますが、基本的に `ed25519` を指定しましょう。 |
| `-C` | コメントです。メールアドレスなどを書きます。 |
| `-f` | ファイル名です。 |

## 補足

* `.pub` が付くほうが、**公開鍵**です。
* 拡張子のないほうが、**秘密鍵**です。
* **秘密鍵は、絶対に自分だけで管理してください。** 以前の現場で、秘密鍵を送ってくる人がいたので、緊急で注意しました。

## まとめ

* 守りたいサーバーには、パスワード認証ではなく、鍵認証を使いましょう。
* `ssh-keygen -t ed25519 -C <コメント> -f <ファイル名>` で、鍵ペアを作れます。
* 秘密鍵は、他人に渡さず、自分だけで管理します。
