Javaで、mainメソッドを持たないクラスを、手元で動作確認する方法をまとめました。
自分が書いたコードを、素早く試したいJava初学者の方に向けた内容です。

## 結論

mainメソッドを持つ**テスト用のクラスを新しく作って**、そこから動作を確認しましょう。
本番のコードにmainメソッドを追加するのは避けます。
本格的にテストするなら、JUnitがおすすめです。

## テストの目的

テストは、開発したコードに不具合がないか、仕様どおりに開発できているかを確認することです。
作ったら終わりではなく、あらゆるパターンを考えて、そのパターンに対応できているかを確認する必要があります。
確認することで、品質が保証されて、仕様書で決めた目的も達成できます。

本来は、開発のあとに、単体テスト、結合テスト、システムテストの工程があって、テスト仕様書のとおりに実施します。
今回は、自分が書いたコードが、目的の動作になっているかを、自分で確認する方法を紹介します。

## テストの考え方

次の考え方を大事にしましょう。

* **書いたら試す**
* **人が手を加えたものには、ミスが起こると考える**
* **ミスを少しでも0に近づけるために実施する**

## mainメソッドがないクラスのテスト方法

自分で書いたコードは、実行すれば動作を確認できます。
ですが、mainメソッドのないクラスは、そのままでは実行できないので、動くかどうか分かりません。

そんなときは、**mainメソッドを持つテスト用のクラスを新しく作って**、書いたコードを試します。

```java
// テスト対象のクラス
public class Animal {
    public String name;
    public int age;

    public void showProfile() {
        System.out.println("名前は、" + name + "、" + age + "歳です。");
    }

    public void speak() {
        System.out.println("......");
    }
}
```

```java
// テスト用のクラス
public class TestAnimal {
    public static void main(String[] args) {
        Animal animal = new Animal();
        animal.name = "ポチ";
        animal.age = 3;

        animal.showProfile(); // メソッドのテスト
        animal.speak();       // メソッドのテスト
    }
}
```

これで、mainメソッドのないクラスでも、自分の環境で動作を確認できます。

mainメソッドを追加するときは、本番のコードには追加せず、`Test〜` のように、新しいクラスを用意してください。
本番のコードに追加すると、提出するときに、mainメソッドを削除しなければいけません。
人が手を加えるとミスが起きるので、せっかくのテストが無駄になってしまいます。

## 上手なテスト

テストには、**正常系**と**異常系**があります。

* **正常系**: 開発したプログラムが、正常に動くかを試します。
* **異常系**: 引数に、想定外の値を渡して試します。

正常系は、動くかどうかを調べるだけなので簡単ですが、異常系は工夫が必要です。
次のコードは、足し算をしています。異常系を試すなら、引数にマイナスの値や `null` などの予想外の値を渡します。

```java
public class Calc {
    private int total;

    public int numTotal(int num1, int num2) {
        total = num1 + num2;
        return total;
    }
}
```

## まとめ

* mainメソッドのないクラスは、テスト用のクラスを作って試します。
* 本番のコードには、mainメソッドを追加しません。
* 正常系と異常系の両方をテストしましょう。
* 本格的に行うなら、JUnitを使うのがおすすめです。
