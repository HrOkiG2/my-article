tmuxでよく使う操作を、備忘録としてまとめました。
tmuxを使い始めたばかりの方に向けた、短いメモです。

## 結論

Prefixキー(デフォルトは `Ctrl-b`)のあとに、キーを押して操作します。

## 前提

* `-` は、同時押しです。
* `+` は、そのあとに単独で押します。(例: `Ctrl-b` を押したあとに `s`)

## 既存のセッションから、ほかのセッションに切り替える

すでにtmuxのセッション内にいる場合は、次の手順で切り替えます。

1. **Prefixキー**(デフォルトでは `Ctrl-b`)を押します。
2. `s` キーを押して、セッション一覧を表示します。
3. 矢印キーで目的のセッションを選んで、Enterキーで切り替えます。

## ペインの削除方法

1. **削除したいペインにフォーカスを合わせます。** `Ctrl-b` を押して、矢印キーで移動します。
2. **ペインを削除します。** `Ctrl-b` のあとに `x` を押します(確認が出たら、`y` を押します)。

## ペインの強制削除

ペイン内で、次のコマンドを実行します。

```bash
exit
```

## セッションの開始

```bash
tmux new -s 'session-name'
```

## セッション名の変更

```bash
tmux rename-session -t 変更前セッション名 変更後セッション名
```

## まとめ

* セッションの切り替えは、`Ctrl-b` のあとに `s` です。
* ペインの削除は、`Ctrl-b` のあとに `x` です。
* セッションの作成と名前変更は、`tmux new -s` と `tmux rename-session` です。
