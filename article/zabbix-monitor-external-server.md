> 初出: 2023年2月17日(旧ブログの記事を移行・加筆)

Zabbixで、別のサーバーを監視する設定を、備忘録としてまとめました。
localhost上のサーバーを監視する記事が多かったので、外部サーバーの監視方法を知りたい方に向けた内容です。

## 結論

監視される側のサーバーに、**Zabbixエージェント**を入れて、設定ファイルを編集します。
`Hostname` は、Zabbixサーバーに登録したホスト名と、完全に一致させる必要があります。

## 考え方

基本的には、「監視するサーバー」と「監視されるサーバー」を分けるのが理想だと考えています。
監視したいサーバー自身にZabbixを入れると、そのサーバーが死んだときに、監視もできなくなるからです。
そのため、ここでは、**監視される側のサーバーの設定**を行います。

## 環境

* Ubuntu 22.04
* Zabbix server 5系
* Zabbix agent 5系

## 設定

### ① Zabbixサーバーのインストールと設定

割愛します。Google検索で、たくさん情報が見つかります。

### ② Zabbixサーバーでホストを登録する

こちらも割愛します。

### ③ 監視される側のサーバーを設定する

監視される側には、**Zabbixエージェント**が必要です。
サーバー内でデーモンのように動いて、結果を、監視サーバーに渡してくれます。

エージェントをインストールします。

```bash
apt install zabbix-agent
```

設定ファイルを編集します。

```bash
nano /etc/zabbix/zabbix_agentd.conf
```

```
Server=<ZabbixサーバーのIPアドレス>        # 監視する側
ListenIP=<監視される側のサーバーのIPアドレス>  # Zabbixエージェントのアドレス
ServerActive=<ZabbixサーバーのIPアドレス>  # 監視する側
Hostname=test                              # ②で登録したホスト名と同一の名前
```

:::message alert
**Hostnameは、②で登録したホスト名と同一の名前にしないと、エラーになります。**
(原因が分からず、1日つぶしました。)
:::

エージェントを再起動します。

```bash
systemctl restart zabbix-agent.service
```

ファイアウォールのポートを開放します。

```bash
ufw allow 10050
ufw allow 10051
```

ポートは、標準で決まっています。

* Zabbixエージェントは、**10050番**ポートで、Zabbixサーバーからのアクセスに応答します。
* Zabbixサーバーは、**10051番**ポートで、Zabbixエージェントからのアクセスに応答します。

この設定が終われば、監視するサーバーと、監視されるサーバーの間で、通信が完了します。

## まとめ

* 監視する側と、監視される側のサーバーは、分けるのが理想です。
* 監視される側には、`zabbix-agent` をインストールします。
* `Hostname` は、Zabbixサーバーに登録した名前と同じにします。
* ファイアウォールで、10050番と10051番ポートを開けましょう。
