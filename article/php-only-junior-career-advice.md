> 初出: 2023年12月10日(旧ブログの記事を移行・加筆)

「PHPだけできる」エンジニアが、なぜ軽く見られがちなのか。その理由と、PHPerが取るべき対策を書きました。
対象読者は、IT業界1〜3年目のプログラマ、特にPHPerの方です。

## 結論

* PHPの最新機能と型システムを学んで、「正しいPHP」を書けるようになりましょう。
* PHPに加えて、フロントエンドかインフラのスキルを身につけましょう。
* PHPは今でも、世の中に価値を届けられる素晴らしい言語です。

## 事の発端

副業案件を探していくつか面談を受けたときに、面接官からこう言われました。

> PHPはネットに落ちているコードで簡単に作れるでしょ。納期短いけどどうにかしてくれ。

いやぁ、恐ろしいですね。
要件次第で難易度が変わるのがシステム開発のはずです。
それなのに「PHPで作るシステムは簡単」と考える人がいました。

そもそも「PHPで作れば開発が楽になる」という考え方自体がおかしいのですが、なぜここまでPHPの立ち位置が低いのか、自分なりに考えてみました。

## PHPが軽く見られる原因

### 駆け出しエンジニアが増えすぎた

PHPは、**駆け出しエンジニアが最初に選ぶ言語**という特色があります。
(私も最初に選んだ言語はPHPでした)

選ばれやすいぶん、ロースキルのプログラマが大量に生まれて、業界内の評価が下がったのではないでしょうか。
2020〜2023年ごろにあった、インフルエンサーによるフリーランスの勧めの波も、影響していると思います。

発注側から見ると、経験が浅いのに「PHPできます」と言う人に不信感を抱くのも、当然かもしれません。

### 自由に書けてしまう

PHPは、型を指定せずにコードを書ける柔軟さがあります。
素早く書ける利点がある反面、実行するまでエラーに気づけず、デバッグや修正に手間取ることがあります。

この柔軟さから「動くものは簡単に作れる」というイメージが生まれました。
結果として、経験豊富な開発者には好まれない傾向があります。(私の上司もPHPの言語仕様が嫌いです。笑)
セキュリティや安定性が求められる場面では、特にリスクになり得ます。

### 過去にインシデントが多数報告されている

[JVN(脆弱性対策情報データベース)](https://jvn.jp/jp/all.html#y2022)を見ると、PHPに関する報告も多く上がっています。
PHPに限らず、インシデントの内容を見ると勉強になるので、一度見に行ってみるのがおすすめです。

## じゃあPHPerはどうするの？

### 正しいPHPを学ぶ

PHPの最新機能や改善点を把握して、セキュアで効率的なコーディングを心がける必要があります。
(エンジニアなら当たり前だ、と言われそうですが。)
私もPHP8の `match` 式を知らなかった時期があります。しっかり学びましょう。

静的型付け言語ほど厳格ではありませんが、次の2点を意識しましょう。

* PHPの型システムを使ったセキュアなコーディング
* ジェネレータを使った、メモリの過剰な消費を防ぐコーディング

### PHP以外のスキルも身につける

新卒が優秀になってきたことや、ChatGPTの登場もあって、**PHPだけができる人は不要になりつつある**と肌で感じます。
そのため、次のどちらかに、スキルの幅を広げる必要があると思います。

* PHP + フロントエンド(React or Vue + TypeScript)
* PHP + インフラ

私はフロントがあまり得意ではないので、インフラ周りを勉強中です。

PHP以外のスキルを身につけると、単価が上がります。
たとえば、PHP + AWS や、PHP + React + TypeScript の案件に関われる可能性が出てきます。
PHPの枠を出ると、確実に世界が広がります。

## PHPは素晴らしい言語だぞ

近年のPHPは、安全性や効率性を高める方向に進化しています。

* PHP 8や8.1では、型付きプロパティや名前付き引数などの新機能が追加されました。
* PHP 8.2では、`readonly class` が追加されました。

これらによって、コードの品質向上やエラーハンドリングの改善が実現しています。

そして何より、PHPには数多くのシステム開発の実績があります。
2023年ごろから「PHPはレガシーだ」という意見も出てきましたが、今も現役で動いているシステムがたくさんあります。
先輩PHPerたちが遺してくれた仕事は、これからもまだまだ増えていくでしょう。

批判されがちなPHPですが、世の中に価値を届けられる可能性に満ちた言語です。
正しい知識と、幅広い知識を持ったPHPerになっていきましょう。

## まとめ

* PHPが軽く見られるのは、駆け出しの増加、自由な書き方、過去のインシデントが背景にあります。
* 対策は、正しいPHPを学ぶことと、PHP以外のスキルを足すことです。
* PHPは今も進化していて、実績も豊富な言語です。
