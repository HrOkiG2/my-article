英語の学習として、PHPを中心にしてきたプログラマーが、AWSの業務でPythonに苦戦していることを書いた日記です。
PHPからPythonに挑戦している方に向けた、短い記録になります。

## English

Facing challenges with AWS tasks recently has brought me to a hurdle: my inability to write Python.
AWS often uses Python for implementing Lambda functions.
Having primarily focused on PHP throughout my career, even simple tasks in Python require extra effort for me.
Struggling with basic conditional statements and debugging are significant issues.

I know I need to start with Python tutorials to overcome this problem, but it's frustrating to add another task to my list, especially when I'm also lacking in infrastructure knowledge.
However, I understand that this situation is necessary for my growth and stepping up.
I'm determined to motivate myself and keep pushing forward.
Hang in there, me.

## 日本語

最近、AWSの業務に取り組むなかで、困っていることがあります。
それは、**Pythonが書けない**ということです。

AWSでは、Lambda関数の実装などで、Pythonを使います。
私は、これまでPHPを主軸にキャリアを歩んできたので、Pythonでの簡単な実装でも、一手間かかってしまいます。
単純な `if` 文や、そのデバッグに時間がかかってしまうのが、大きな問題です。

この問題を解消するには、Pythonのチュートリアルから始める必要があります。
ですが、インフラの知識もないなかで、やることがまた1つ増えて、腹が立ちます。
ただ、この状況は、ステップアップのために必要なものなので、自分を奮い立たせていきたいです。

頑張れ、自分。

## まとめ

* AWSのLambdaでは、Pythonを使うことが多いです。
* PHPしか書いてこなかったので、Pythonは基本から学び直す必要があります。
* インフラの知識とあわせて、少しずつ学んでいきます。
