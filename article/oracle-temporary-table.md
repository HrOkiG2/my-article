Oracleの一時表の使い道と、作成方法をまとめました。
ORACLE MASTER Silver SQLの試験勉強をしている方や、データ移行の確認などに一時表を使いたい方に向けた内容です。

## 結論

一時表は、**データを一時的に預かってくれる表**です。
テーブル定義が残るのが「グローバル一時表」、定義も消えるのが「プライベート一時表」です。

## 一時表とは

名前のとおり、データを一時的に預かる表です。
セッションやトランザクションが終了すると、データが削除されるので、構文を試したいときなどに使えます。

私は、同じDB内でデータ移行をしたときに、正しく移行できているかを確認するために使いました。

```sql
-- 一時表を作って、元のデータを入れる
CREATE GLOBAL TEMPORARY TABLE TEST AS SELECT * FROM HOGE;

-- 構造だけを同じにした一時表(データなし)
CREATE GLOBAL TEMPORARY TABLE FUGA AS SELECT * FROM HOGE WHERE 1 = 2;

-- データ移行
INSERT INTO FUGA
SELECT * FROM HOGE;
```

## グローバル一時表とプライベート一時表

どちらも一時表ですが、次の違いがあります。

| | 内容 |
| --- | --- |
| 共通 | セッション、トランザクションの終了時に、データが削除されます。自分のセッション以外からは参照できません。セッションごとに一時表は独立しています。 |
| **GLOBAL** | セッション、トランザクションの終了後も、**テーブルの定義が残ります**(データディクショナリに保存されるため)。いつでも再利用できます。テーブル定義は、`DROP TABLE` で削除します。 |
| **PRIVATE** | セッション、トランザクションの終了時に、**データと一緒にテーブル定義も削除**されます。定義情報も消えるので、気軽に試せます。作成時には、テーブル名に **`ORA$PTT_`** を付ける必要があります(設定で変更可能)。 |

:::message
プライベート一時表は、Oracle 18c以降で使えます。
:::

## 作成方法

### グローバル一時表

```sql
CREATE GLOBAL TEMPORARY TABLE AAA (
  -- カラム定義
)
-- オプション
ON COMMIT PRESERVE ROWS;  -- セッション終了時にデータを削除
-- または
-- ON COMMIT DELETE ROWS; -- トランザクション(COMMIT)終了時にデータを削除
```

### プライベート一時表

```sql
CREATE PRIVATE TEMPORARY TABLE ORA$PTT_BBB (
  -- カラム定義
)
-- オプション
ON COMMIT PRESERVE DEFINITION;  -- セッション終了時に、定義を削除
-- または
-- ON COMMIT DROP DEFINITION;   -- トランザクション終了時に、定義を削除
```

## まとめ

* 一時表は、データを一時的に預かる表で、セッションやトランザクションの終了でデータが消えます。
* グローバル一時表は、テーブル定義が残ります。
* プライベート一時表は、定義も消え、`ORA$PTT_` の接頭辞が必要です。
