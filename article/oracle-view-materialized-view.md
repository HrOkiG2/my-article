Oracleのビューとマテリアライズドビューの基本を、まとめました。
ORACLE MASTER Silver SQLの試験勉強をしている方や、ビューの使いどころを知りたい方に向けた内容です。

## 結論

* ビューは、**SELECT文を格納しておく、変数のようなもの**です。
* SELECT文の共通化と、見せたくないデータを隠す用途で使います。
* ビューは、見るたびに元のテーブルを参照します。マテリアライズドビューは、結果をデータとして保持します。

## ビューとは

ビューは、SELECT文を格納しておく変数のようなものです。
プログラムを学んだ方なら、しっくりくると思います。
共通化することで、いろいろな場面で簡単に呼び出せます。

## 作成構文

```sql
SQL> select * from test;

        NO NAME
---------- ----------
         1 aaaaa
         2 ooooo
         3 oooaa

SQL> create or replace view test_view as
  2  select * from test;

View created.

SQL> select * from test_view;

        NO NAME
---------- ----------
         1 aaaaa
         2 ooooo
         3 oooaa
```

## 使い方

### SELECT文の共通化

ビューを作ると、SELECT文を共通化できます。
システムの中で値を取得するたびにSELECT文を書くよりも、SELECT文を格納したビューを呼び出すほうが効率的で、記述ミスも防げます。
プログラムの変数と、同じような扱いです。

### 値を隠す

権限でもできる話ですが、見られたくないデータを隠すためにも、ビューを使います。

たとえば、「社員名、年齢、性別、給与、持病」を持つテーブルがあるとします。
社員名、年齢、性別は見られても問題ありませんが、給与や持病のようなプライベートなデータは、案件によっては隠したいはずです。
そこで、一般社員が業務で使うデータとして「社員名、年齢、性別」をAビューに格納して、すべての項目を持つビューは、管理者用に使う、という使い分けができます。

## マテリアライズドビュー

ビューには、通常のビューと、マテリアライズドビューの2種類があります。

| 種類 | 特徴 |
| --- | --- |
| ビュー | SELECT文を保存しているだけで、見るたびに元のテーブルを参照します。 |
| マテリアライズドビュー | 結果のデータを保持します。元のテーブルの更新を反映する(リフレッシュする)ことができます。 |

マテリアライズドビュー(マテビュー)は、ビューとテーブルが同期しているイメージです。
元のテーブルが更新されると、マテビューも更新されます。
更新方法(自動か手動か)は、作成時に指定できます。

```sql
SQL> create materialized view test_mat as
  2  select * from test;

Materialized view created.

SQL> select * from test_mat;

        NO NAME
---------- ----------
         1 aaaaa
         2 ooooo
         3 oooaa

SQL> truncate table test;

Table truncated.

SQL> select * from test_mat;
-- リフレッシュの設定によって、結果が変わります
```

:::message
上の例では、元のテーブルを `TRUNCATE` したあとの結果が、マテビューのリフレッシュ方法(`ON COMMIT`/`ON DEMAND`)によって変わります。
実際に動かして、挙動を確認してみてください。
:::

## まとめ

* ビューは、SELECT文を格納しておく仕組みで、共通化とデータの隠蔽に使います。
* マテリアライズドビューは、結果を保持して、元のテーブルと同期できます。
* 更新方法は、作成時に自動か手動かを指定できます。
