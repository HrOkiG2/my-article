PHP8で導入された `match` 式の特徴と、`switch` より便利な点をまとめました。
条件分岐で値を変数に代入する処理を、もっとスッキリ書きたいPHPエンジニアの方に向けた内容です。

## 結論

値を返す条件分岐は、`switch` ではなく `match` 式で書くのがおすすめです。
厳格比較なのでバグが入りにくく、記述量も少なくなります。

## match式とは

PHP8から導入された条件式です。
`switch` や `if` といった条件式と並ぶ立ち位置です。

```php
$r = match($x) {
    0 => "おはよう",
    1 => "こんにちは",
    2 => "こんばんは",
    default => "",
};
```

### 特徴

* 型と値の厳格比較(`===`)で判定します。
* 結果を変数に代入しやすいです。
* 少ない記述量で条件分岐できます。

## 何が便利なの？

### バグが入りにくい

個人的に一番のメリットだと感じているのは、**厳格な型比較**をしてくれることです。
PHPの曖昧な比較で起きがちな、思わぬバグが入りにくくなります。

`default` を指定すれば、条件に一致しない場合も制御でき、後続の処理を続けられます。

:::message
`default` を省略して、どの条件にも一致しなかった場合は、`UnhandledMatchError` が発生します。
一致しないケースがあり得るなら、`default` を忘れずに書きましょう。
:::

### 戻り値を変数に代入できる

`match` は式なので、戻り値をそのまま変数に代入できます。
値を代入する処理は、`match` 式で書くのがベストだと思います。

```php
// できない(if は式ではない)
$x = if ($a === '') {}

// できない(switch は式ではない)
$x = switch ($a) {
    case '':
        return 'a';
        break;
}

// できる
$x = match($a) {
    1 => 'a',
    default => 'b',
};

// 扱いやすいが else が必要
// (else が不要な場合や、else if が必要な場合は使いにくい)
$x = ($a === '') ? 'a' : 'b';
```

### 記述が少ない

`switch` と比べて、次のような記述が不要です。

* `case` ごとの `break`
* 値を代入するための、変数への個別の代入

そのぶん、可読性が圧倒的に高くなります。
これだけでも、使う価値があります。

## まとめ

* `match` 式は、PHP8で導入された条件式です。
* 厳格比較(`===`)で判定するので、バグが入りにくいです。
* 戻り値を変数に代入できて、記述量も少なく済みます。
* 一致しない場合に備えて、`default` を書いておきましょう。
* 値を返す条件分岐は、みんな `match` を使おう！
