# my-article

IT業界へ挑戦して以降、日々の開発や運用の中で蓄積してきた技術的な知見・ノウハウを管理する記事リポジトリです。

## 📝 記事一覧
記事のインデックスは、[記事一覧](./article/list.md) を参照してください。
タイトル(記事へのリンク)、分野、種別で整理しています。

## 🛠️ 構成
Markdownで記事を管理するリポジトリです。記事は `article/` 配下に、1記事1ファイルで置いています。

## 🗓️ 記事の日付について
`article/` の記事の多くは、以前運営していたブログの記事を、Markdownに**移行・加筆**したものです。

* コミットの日付は、移行作業を行った日です。**記事を書いた日ではありません。**
* 元記事の投稿日は、各記事の冒頭に `初出` として記載しています。同じ日付を、フロントマターの `published_at` にも記録しています。
* 移行にあたって、文章の整理、誤りの修正、補足の追記を行っています。元の記事と内容が異なる箇所があります。
